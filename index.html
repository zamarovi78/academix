Conexión Supabase & Storage

Gestión de base de datos en la nube y fotos de perfil

Proyecto URL:https://gusbmqyaiacyllexfkkc.supabase.co
Estado:Activo (PostgreSQL)
Pasos para habilitar fotos en Supabase Storage:
  1. En Supabase, entra a Storage › New Bucket.
  2. Nombre del bucket: perfiles.
  3. Activa la casilla "Public bucket" y guarda.
  4. Ejecuta el script de la pestaña "Permisos SQL" para habilitar las políticas de acceso.
-- Script de Creación y Permisos Supabase
ALTER TABLE IF EXISTS public.aprendices ADD COLUMN IF NOT EXISTS foto TEXT;
ALTER TABLE IF EXISTS public.instructores ADD COLUMN IF NOT EXISTS foto TEXT;

INSERT INTO storage.buckets (id, name, public)
VALUES ('perfiles', 'perfiles', true)
ON CONFLICT (id) DO UPDATE SET public = true;

CREATE POLICY "Public Read perfiles" ON storage.objects FOR SELECT USING (bucket_id = 'perfiles');
CREATE POLICY "Public Insert perfiles" ON storage.objects FOR INSERT WITH CHECK (bucket_id = 'perfiles');
